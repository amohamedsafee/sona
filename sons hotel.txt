To run the **Sona Luxury Hotel** project properly, follow the guide below.

---

### 1. Prerequisites Check

- **Node.js**: Installed (`v26.7.0` is already installed on your machine).
- **MySQL / MariaDB**: Installed via **XAMPP** at `C:\xampp`.

---

### 2. Step-by-Step Instructions

#### **Step 1: Start MySQL Service**
Ensure the MySQL database server is running on port `3306`:
- **Option A (GUI)**: Open **XAMPP Control Panel** (`C:\xampp\xampp-control.exe`) and click **Start** next to **MySQL**.
- **Option B (PowerShell)**:
  ```powershell
  Start-Process -FilePath "C:\xampp\mysql\bin\mysqld.exe" -ArgumentList "--defaults-file=mysql\bin\my.ini --standalone" -WorkingDirectory "C:\xampp" -WindowStyle Hidden
  ```

---

#### **Step 2: Database Initialization (First Time or Reset)**
This automatically creates the `sona_hotel_db` database, applies [schema.sql](file:///d:/HTML/sona/backend/database/schema.sql), and populates initial sample data via [seed.sql](file:///d:/HTML/sona/backend/database/seed.sql).

From the project root:
```bash
npm run init-db
```
*(Or navigate to `backend/` and run `node database/init-db.js`)*.

---

#### **Step 3: Start the Application Server**
The backend Express server serves the REST APIs, the guest website, and the administration panel.

From the project root:
```bash
npm start
```
*(Or inside the `backend` folder: `node server.js`)*.

You will see:
```text
====================================================
 Sona Luxury Hotel Backend Server
 Server running on: http://localhost:5000
 Admin Panel URL:   http://localhost:5000/admin/
 Website Homepage:  http://localhost:5000/index.html
 API Endpoint:      http://localhost:5000/api/health
====================================================
[Database] Successfully connected to MySQL database: sona_hotel_db
```
