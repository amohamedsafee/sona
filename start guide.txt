================================================================================
          SONA LUXURY HOTEL RESERVATION & MANAGEMENT SYSTEM
                             START GUIDE
================================================================================

This guide contains complete step-by-step instructions to run both the 
Frontend Guest Website, Backend Node.js/Express API, and the Admin Portal.

--------------------------------------------------------------------------------
1. SYSTEM PREREQUISITES
--------------------------------------------------------------------------------
- Node.js (v18 or higher installed on your machine)
- XAMPP / MySQL Server (installed at C:\xampp)
- Web Browser: Google Chrome, Mozilla Firefox, or Microsoft Edge

--------------------------------------------------------------------------------
2. STEP-BY-STEP STARTUP INSTRUCTIONS
--------------------------------------------------------------------------------

STEP 1: START THE MYSQL DATABASE SERVICE
----------------------------------------
Before launching the server, MySQL must be active on port 3306.

Option A (Recommended - XAMPP GUI):
1. Open XAMPP Control Panel (C:\xampp\xampp-control.exe).
2. Click the "Start" button next to MySQL.
3. Verify that the MySQL status turns green and port 3306 is active.

Option B (PowerShell Command Line):
Open PowerShell and run:
Start-Process -FilePath "C:\xampp\mysql\bin\mysqld.exe" -ArgumentList "--defaults-file=mysql\bin\my.ini --standalone" -WorkingDirectory "C:\xampp" -WindowStyle Hidden


STEP 2: INITIALIZE / RESET DATABASE (FIRST TIME ONLY)
----------------------------------------------------
This script creates the `sona_hotel_db` database, sets up all relational 
tables (rooms, bookings, admins, messages), and seeds initial room & admin data.

In the project root folder (D:\HTML\sona), open a terminal and run:
   npm run init-db

(Alternative: navigate to backend folder: cd backend && node database/init-db.js)

Expected output:
   [Database] Connected to MySQL server successfully.
   [Database] Schema applied successfully.
   [Database] Seed data inserted successfully.


STEP 3: START THE APPLICATION SERVER
------------------------------------
In the project root folder (D:\HTML\sona), run:
   npm start

(Alternative: navigate to backend folder: cd backend && node server.js)

When started successfully, you will see:
====================================================
 Sona Luxury Hotel Backend Server
 Server running on: http://localhost:5000
 Admin Panel URL:   http://localhost:5000/admin/
 Website Homepage:  http://localhost:5000/index.html
 API Endpoint:      http://localhost:5000/api/health
====================================================
[Database] Successfully connected to MySQL database: sona_hotel_db

Keep this terminal window open while using the application.

--------------------------------------------------------------------------------
5. COMMON TROUBLESHOOTING
--------------------------------------------------------------------------------
Problem: "ECONNREFUSED 127.0.0.1:3306"
Solution: MySQL is not running. Open XAMPP Control Panel and start MySQL.

Problem: "Port 5000 is already in use"
Solution: Stop any existing Node processes in Task Manager or run:
Stop-Process -Name node -Force

Problem: "npm start does not find backend"
Solution: Ensure you run the command from the root folder (D:\HTML\sona).
Alternatively: cd D:\HTML\sona\backend && node server.js

--------------------------------------------------------------------------------
To shut down the project when finished:
Press CTRL + C in the terminal running the server, then stop MySQL in XAMPP.
